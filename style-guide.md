# Стил „OCCT“ — бележки за дизайна

Източник: https://www.ocbase.com/occt-personal-use (прегледан на 2026-10-28).
Целта е да вземем **визуалния език**, не съдържанието, логото или марката им.

## Характер

Тъмен „геймърски / хардуерен“ стил: почти черен фон, един ярък червен акцент,
всичко с главни букви, техно-шрифт за заглавията и **скосени ъгли навсякъде**
(clip-path полигони вместо border-radius). Много въздух, центрирани заглавия,
секциите се редуват между малко по-светъл и малко по-тъмен черен.

## Цветове

|------------------|-----------------------|--------------------------------------------|

| `--bg`           | `#121212`             | основен фон на body                        |
| `--bg-alt`       | `#161619`             | „светли“ секции                            |
| `--bg-deep`      | `#0F0F11`             | „тъмни“ секции, долен край на градиентите  |
| `--surface`      | `#252529`             | табове / неактивни бутони                  |
| `--line`         | `#1A1A1D`             | 2px рамка на картите                       |
| `--footer`       | `#000000`             | футър                                      |
| `--header`       | `rgba(0,0,0,.9)`      | фиксиран хедър                             |
| `--text`         | `#EDEDED`             | основен текст                              |
| `--text-strong`  | `#FFFFFF`             | заглавия                                   |
| `--text-muted`   | `#B1B1B1`             | подзаглавия, дати, второстепенен текст     |

Голямата CTA лента („Join the community“) е изцяло в `--accent` с бял текст.

## Типография

> **За GSOL:** Oxanium и Archivo нямат кирилица. В сайта ползваме **Tektur** вместо Oxanium
> (същият ъглов техно характер) и **Onest** вместо Archivo (тънък гротеск, weight 300).

- **Заглавия:** `Oxanium` (Google Fonts), винаги `uppercase`, `letter-spacing: .5px`
  - H1 / заглавие на секция: 40px, weight 500, line-height ~1.17
  - H2 в карти и блокове: 25px, weight 400
  - Заглавия на новини: 18px, weight 400
  - Бутони: 12px, weight 500
- **Текст:** `Archivo` (Google Fonts), weight **300** (тънък), 15px / 20px, `letter-spacing: .5px`
  - Лийд текст под H1: 18px / 27px, цвят `--text-muted`
- **Подзаглавие (tagline) под H1:** Archivo 15px, weight 400, uppercase, `letter-spacing: 1.5px`
- **Eyebrow над заглавие:** Archivo 15px, uppercase, `letter-spacing: 1.5px`, `--text-muted`,
  с малък червен паралелограм отляво (SVG 15×15)
- **Акцентна дума:** част от заглавието е в червено — „INTRODUCING **OCCT**“,
  „OCCT **FEATURES**“, „**TEST THE STABILITY** OF YOUR PC“

## Подписващият елемент: скосени ъгли

### Бутон (височина 25px, padding 0 25px)
```css
clip-path: polygon(0 100%, 7px 10px, 20px 0, 100% 0,
                   calc(100% - 7px) calc(100% - 10px), calc(100% - 18px) 100%);
```
- **Contained:** фон `--accent`, бял текст.
- **Outlined:** 2px червена рамка (рисувана с `::before`/`::after` клинове + border),
  прозрачен фон. При hover се запълва с червено отляво надясно:
  `background: linear-gradient(to right, var(--accent) 50%, transparent 50%);
   background-size: 210% 100%; background-position: 100%; transition: .3s ease-out;`
  → на hover `background-position: 0`.

### Карта (feature card)
```css
clip-path: polygon(0 100%, 0 50px, 50px 0, 100% 0,
                   100% calc(100% - 50px), calc(100% - 48px) 100%);
border: 2px solid #1A1A1D;
background: linear-gradient(150deg, transparent 50%, rgba(255,0,43,.1) 100%);
padding: 32px;
```
Горен-ляв и долен-десен ъгъл са скосени; лек червен отблясък в долния десен ъгъл.
Иконата горе е червена (линейна, ~32px).

### Изображения / медия
Същият полигон с 40–50px срязване. За „брандови“ плочки (Patreon, Steam) —
силно наклонен паралелограм: `polygon(0 101%, 14% 22%, 33% 0, 100% 0, 86% 78%, 67% 101%)`.

### Табове (вертикално меню)
225×41px, фон `--surface`, по-малко срязване (10px), иконка + текст 12px Oxanium.
Активният таб е изцяло червен.

## Хедър

- `position: fixed`, височина 70px, фон `rgba(0,0,0,.9)`
- **2px червена линия най-отгоре** (`box-shadow: inset 0 2px 0 var(--accent)`)
- Ляво: лого + навигация (Archivo 300, 15px, uppercase, бяло, малки разстояния)
- Дясно: червен бутон DOWNLOAD + иконки

## Структура на страницата (отгоре надолу)

1. **Hero** — цял екран (100vh), видео/снимка на фона, тъмен градиент отдолу
   (`linear-gradient(0deg, #0F0F11 15%, transparent 55%)`), H1 + лийд + бутон центрирани
   в долната трета, анимирана стрелка „надолу“ (двоен chevron, червен).
2. **Лента с новини** — 3 колони: миниатюра + заглавие (18px) + дата (muted).
3. **Intro** — центрирано заглавие с червена дума + tagline + параграф + голяма
   снимка/видео на продукта; под нея 3 feature карти; бутон LEARN MORE.
   Фон: градиент `#161619 → #0F0F11`.
4. **Features с табове** — вертикални табове вляво, голяма скосена карта вдясно
   с фонова снимка, затъмнена отляво (`linear-gradient(to right, #000 0%, rgba(0,0,0,.8) 20%, transparent)`).
5. **2 медийни карти** един до друг (снимка горе, eyebrow + заглавие + текст долу).
6. **Пълноширочинен банер** със затъмнена снимка и центрирано заглавие + бутон.
7. **Редуващи се блокове** снимка/текст (зигзаг), с наклонени брандови плочки.
8. **Червена CTA лента** — заглавие, tagline, ред социални иконки (бели).
9. **Футър** — черен; лого + кратко описание вляво, 4 колони линкове
   (заглавие на колона с червен маркер), долна лента с копирайт и квадратни
   скосени социални бутони.

## Ритъм и оформление

- Контейнер: max-width **1200px**, padding 0 16px; grid gap 32px
- Голямо вертикално разстояние между секциите (~120–160px)
- Заглавията на секциите са центрирани; текстовите блокове в зигзага — ляво подравнени
- Бутон „нагоре“ фиксиран долу вдясно (бял chevron)
- Фина червена вертикална линия (2px) като декоративен разделител на места

## Как ще го ползваме

При новия сайт: взимаме токените, шрифтовете, скосените ъгли и реда на секциите,
а слагаме **собствено** име, лого, текстове и снимки.
