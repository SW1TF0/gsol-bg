# GSOL.bg — нов сайт

Онлайн магазин и сайт за услуги на GSOL с админ панел. Next.js 16 + Supabase.
Визията следва [style-guide.md](style-guide.md), а планът и решенията са в [gsol-analiz.md](gsol-analiz.md).

## Стартиране

```bash
npm install
npm run dev
```

Сайтът: http://localhost:3000 · Админ панелът: http://localhost:3000/admin

`.env.local` съдържа само публичните стойности от `.env.example` (URL и публичен ключ на Supabase).
Таен ключ не е нужен: цените, промо кодовете и поръчките се изчисляват и записват в базата
(`quote_order`, `place_order`), а админът работи със сесията на служителя през RLS.

**Имейли (по желание).** Писмата при поръчка, запитване и смяна на статуса минават през Resend.
Без `RESEND_API_KEY` в `.env.local` сайтът работи нормално, но не изпраща писма (виж `.env.example`).
Преглед на писмата и стъпките за включване: Админ → Настройки → Имейли.

## Структура

| Път | Какво е |
|---|---|
| `src/app/(shop)` | магазин: начало, каталог, продукт, промоции, търсене, количка, поръчка, томболи, страници |
| `src/app/admin` | админ панел: вход, табло, поръчки, продукти, промо кодове, томболи, запитвания, страници, настройки |
| `src/lib/catalog.ts` | четене на каталога от Supabase (кеш с таг `catalog`) |
| `src/lib/promo.ts` | помощници за промо кодове: генериране, съобщения |
| `src/lib/settings.ts` | фирмени данни, доставка и банкова сметка от „Настройки“ (кеш с таг `settings`) |
| `src/lib/email` | шаблони на писмата, изпращане през Resend и кой какво получава |
| `src/proxy.ts` | обновява сесията и пази `/admin` |
| `supabase/migrations` | схемата на базата, RLS и функциите за поръчка |
| `scripts/fetch-seed.py` | сваля примерни продукти от сегашния gsol.bg |

## Роли в админа

Служител се регистрира от `/admin/vhod`, потвърждава имейла и администратор му дава роля
(таблица `staff`): администратор, мениджър, продажби, техник, редактор.

## Етапи

1. **Основа** — дизайн система, магазин, поръчка, промо кодове, админ за поръчки/продукти/кодове ✅
2. **Растеж** — томболи, запитвания, страници, настройки, имейли ✅; предстоят клиенти, роли и служители в админа.
3. **Автоматизация** — фийдове от доставчици, Еконт API, миграция от WooCommerce, хостинг.
