# GSOL.bg — нов сайт

Онлайн магазин и сайт за услуги на GSOL, изграден наново с Next.js 16. Визията следва
[style-guide.md](style-guide.md), а планът и решенията са в [gsol-analiz.md](gsol-analiz.md).

## Стартиране

```bash
npm install
npm run dev
```

Сайтът се отваря на http://localhost:3000.

## Структура

| Път | Какво е |
|---|---|
| `src/app/(shop)` | публичните страници: начало, каталог, продукт, промоции, търсене, количка |
| `src/components` | хедър, футър, продуктови карти, количка, общи UI елементи |
| `src/lib/catalog.ts` | достъп до продуктите (сега от `src/data/seed.json`, после от Supabase) |
| `src/lib/site.ts` | фирмени данни и навигация |
| `scripts/fetch-seed.py` | сваля примерни продукти от публичното API на сегашния gsol.bg |

## Етапи

1. **Основа** — дизайн система и публичен магазин ✅; поръчка, админ панел и промо кодове — следват.
2. **Растеж** — томболи, CRM за запитванията, CMS, имейли, роли.
3. **Автоматизация** — фийдове от доставчици, Еконт API, миграция от WooCommerce.
